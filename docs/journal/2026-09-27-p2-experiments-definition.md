## 一、为什么先切这一刀

P2 剩余两块：**④ 实验矩阵** 与 **§11.2 并发隔离**。二者关系在方案里是
「并发隔离 = 实验矩阵的前置」，但**执行模型已裁决为「先串行跑通，再评估并发」**
（§4.4）⇒ 串行版实验矩阵**不必等**并发隔离。故先做实验矩阵，且先做它的定义层。

定义层与执行层分开的第二条理由（更硬）：执行器必须回答
「模板参数是否真的被该引擎接受」，而**这一点本步未核实**（未逐参数核对 server 工具面）。
定义层不需要回答它 —— 分开做，定义层可用真实网格先验证，
执行层则由**契约 3 的 fail-closed** 逐格兜底。

## 二、★ 关键设计决定（三条，都可复核）

### 1. 一格 = 一次**显式声明**的工具调用；因子只是标签维度

实验 = 算例集合 × 因子网格 × 一个工具步骤（`server` / `tool` / `args_template`）。

⚠️ **刻意不做「负荷水平」这类语义因子**。方案 §4.4 写的是
「算例 × 负荷水平 × 故障集 × 引擎」，但把「负荷水平怎么施加」编码进网关
= **替引擎声称一个尚未核实的能力**（要某个引擎真能按因子缩放负荷）。
那正是契约层反复否掉的「静默假声明」。
⇒ 声明式模板把选择权交回声明者；参数对不对由契约 3 在调用前拦。

### 2. `cache_key` 只由**可确证的量**构成

```
H(算例当前 sha256 + server + tool + 规范化 args + core_version)
```
⚠️ 方案原文还含**引擎版本**与**IR 版本** —— 网关当前**没有可靠来源**取得
（inventory 只给工具面，不给引擎版本号；IR 无版本字段）。
⇒ **不假装有**：缺的量不进 key，而在响应的 `notes` 里写明。
宁可让 key 保守失效，也不能让它冒充可复现性（后者是假绿灯）。

### 3. 格子**现算不存快照**

`GET` 每次按**当前**算例哈希与模板重算格子 —— 存快照会让
「改了模板但没重跑」的旧格子继续冒充当前定义（静默错配）。
副作用正是要的效果：**算例源文件一改，同一格算出新的 `cache_key` ⇒ 旧结果即为陈旧**。

## 三、诚实边界（都写进了代码 / 响应 `notes`）

| 边界 | 处置 |
|---|---|
| 登记时**不校验** `step.tool` 是否真存在于该 server | 校验需真实拉起 server（秒级），与"登记请求应当廉价"冲突；错误在**执行期**由契约 3 逐格报出，不静默放行 |
| `cache_key` 不含引擎版本 / IR 版本 | 见 §二-2 |
| 本步**不执行** | 全部格子 `status="pending"`；`notes` 明写「执行端点是 P2-①b」。**不出现任何"已成功"的假状态** |
| `by_status` 空集 | 返回 `{}` 而不是 `{pending: 0}` —— 空集 ≠ 全部正常 |

## 四、两条必须严防的渲染缺陷（都有探针）

1. **整串占位符保类型**：`"{load_level}"` → `1.1`（float），**不是** `"1.1"`。
   否则数值参数被渲染成字符串，契约 3 会以"类型不符"拒发 —— 那不是参数错，是渲染层把类型弄丢了。
2. **未知占位符必须报错**，绝不静默留下 `{xxx}`：
   留在参数里的 `{xxx}` 会被当成字面量发给引擎，得到"跑成功了但根本没生效"的结果。

两条各配一条变异探针（M1 / M2a / M2b）。

## 五、端点与错误映射

| 端点 | 说明 |
|---|---|
| `POST /experiments` | 登记；同一定义重复提交 → **200**（`created=false`），新定义 → 201 |
| `GET /experiments` | 列表 + `summary{total, cells}` |
| `GET /experiments/{eid}` | 定义 + 全格（现算）+ `by_status` |

错误映射沿用项目既有约定（**用类型区分，不靠匹配错误文本**）：
400 定义非法 · **409 算例状态不允许（不可读 / 不在围笼，可修复）** · 404 未知 id · 500 索引损坏 · 503 配置失败。

> 409 与 400 的分界：算例**未登记** = 请求体引用了不存在的东西（400，改请求）；
> 算例**存在但不可读 / 不在围笼** = 环境状态不允许（409，改环境）—— 与 `POST /cases/{id}/parse` 同口径。
